================================================================================
TROUBLESHOOTING
================================================================================

Problem: Import errors
Solution: Ensure src/ directory is in PYTHONPATH or adjust imports

Problem: OpenAI API errors
Solution: Check .env file has valid OPENAI_API_KEY

Problem: Database errors
Solution: Ensure data/ and logs/ directories exist and are writable

Problem: Async errors
Solution: Use Python 3.9+, ensure asyncio event loop is running

Problem: Test failures
Solution: Install pytest, pytest-asyncio: pip install pytest pytest-asyncio

Need Help?
   1. Check ASSEMBLY_GUIDE.md troubleshooting section
   2. Review example code
   3. Check Python/pip installation
   4. Verify OpenAI API key
